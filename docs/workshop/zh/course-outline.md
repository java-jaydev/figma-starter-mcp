# 课程进行方案（2 小时，面向开发者）

目标：学员只用一个 Figma 免费（Starter）账号，就能做出一个包含亮色/暗色颜色变量、间距变量、文本样式和 Section 结构的设计系统文件，并能用插件脚本把这个过程自动化。

准备：Figma 桌面应用、免费账号、本仓库的 `docs/workshop/token-plugin/` 文件夹、代码编辑器。
所有限制数值都以 `../../../skills/figma-build/references/limits-and-sources.md` 为准。

## 1. 一览免费计划的墙（10 分钟）

- 讲课笔记：打开 `../../../skills/figma-build/references/limits-and-sources.md` 的表格，按“限制 - 绕过方法”成对地过一遍。介绍这门课会按照实际用 Starter 账号搭建设计系统时碰壁的顺序来讲。
- 强调：数字会变。说明表格里为什么写有确认日期和来源。
- 预期问题：“直接用 Professional 不就行了吗？” - 个人业余项目、学习、小团队早期，免费版就够用了；而且了解这些限制，以后迁移时结构也会更清晰。

## 2. 用 Section 代替页面（20 分钟）

- 讲课笔记：Starter 的设计文件最多只有 3 个页面。设计系统通常会用很多页面，比如 Foundations、Components、Patterns、Playground，这里改为在一个页面内用 Section 来划分。
- 屏幕演示：在工具栏中用 Section 工具（快捷键 Shift+S）画出 Section 并命名。展示左侧图层面板中 Section 可以像文件夹一样折叠。
- 剩下 2 个页面的用法建议：第 1 页 = 系统（用 Section 划分），第 2 页 = 试验场，第 3 页 = 归档。
- 进行实操 1（`labs.md`）。
- 预期问题：“Section 里还能再放 Section 吗？” - 可以。不过嵌套太深会不好找，建议最多两层。

## 3. 用 2 个集合代替模式（25 分钟）

- 讲课笔记：变量模式有按计划划分的限制，在 Starter 中实际上每个集合只能创建 1 个模式。所以在 `Color / Light`、`Color / Dark` 两个集合里创建**同名**变量。
- 与代码对应：向开发者解释，这就相当于在 CSS 的 `:root` 和 `[data-theme="dark"]` 中把同一个变量名定义两次。
- 也要坦白缺点：无法通过一次模式切换来改变整个画面。暗色画面要直接绑定暗色集合的变量，单独制作。以后迁移到付费版时，把两个集合合并成一个、改成 2 个模式即可。
- 进行实操 2（`labs.md`）。手动只做 2 个，然后抛出“如果要做几十个呢？”这个问题，过渡到下一个模块。

## 4. 用开发用插件自动化（35 分钟）

- 讲课笔记：开发用插件是在桌面应用中加载 `manifest.json` 后直接运行的。官方文档中没有计划限制或调用次数限制，所以很适合在 Starter 中承担重复性工作。
- 阅读代码（10 分钟）：一起阅读 `code.js`。
  - `TOKENS`：数据。学员只需要改这里。
  - `getCollection`、`upsertVariable`：如果已有同名项就复用，因此多次运行也不会产生重复。
  - `buildTextStyles`：必须先用 `loadFontAsync` 加载字体，才能把它指定给样式。
  - `buildSections`：把模块 2 中手动做的事用代码完成。
  - `manifest.json` 中的 `documentAccess: "dynamic-page"`：因此要使用 `getLocal...Async` 这类异步 API。
- 进行实操 3（20 分钟）。
- 收尾（5 分钟）：介绍把令牌抽成 JSON，让代码仓库和 Figma 使用同一份值的思路。

## 5. 省着用 MCP（10 分钟）

- 讲课笔记：Figma MCP 服务器让 AI 编程工具可以读写 Figma 文件。Starter 每月的调用次数非常少，用 MCP 搭建设计系统很快就会被卡住（亲身经历）。
- 根据官方文档，部分写入文件的工具不计入限制。消耗额度的主要是读取调用。
- 小结：重复性的生成交给插件，MCP 只在“把完成的画面转成代码”这类真正需要的时刻使用。
- 预期问题：“额度什么时候重置？” - 按月。具体标准一起打开官方 FAQ 确认。

## 6. 字体、库、收尾（10 分钟）

- 字体：新安装的字体需要重启桌面应用才会显示。把这一点写进课前准备说明。
- 库：Starter 很难通过团队库共享。所以没有把文件拆成“令牌文件、组件文件”，而是集中在一个文件里。这也正好符合文件数（3 个）的限制。
- Q&A。
