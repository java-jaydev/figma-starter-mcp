# 演習ガイド

## 演習 0. 準備 (講座前)

1. Figma デスクトップアプリをインストールし、無料アカウントでログインします。
2. 使いたいフォントがあれば事前にインストールし、Figma アプリを完全に終了してから開き直します。この演習では Figma の標準フォントである Inter を使うので、インストールは不要です。
3. このリポジトリをダウンロードし、`docs/workshop/token-plugin/` フォルダの場所を覚えておきます。

## 演習 1. Section で区画を分ける (約10分)

1. 新しいデザインファイルを作り、名前を `My Design System` に変更します。
2. 左上のページ名を `System` に変更します。
3. Section ツール(Shift+S)で大きな四角形を3つ描き、名前を `01 Foundations`、`02 Components`、`03 Patterns` にします。
4. 確認: レイヤーパネルに Section が3つ表示され、折りたたみと展開ができます。

## 演習 2. ライト/ダークのコレクションを手作業で作る (約10分)

1. 何も選択していない状態で、右パネルの Variables を開きます。
2. コレクションを新規作成し、名前を `Color / Light` にします。
3. 色変数 `bg/default` = `#FFFFFF`、`text/default` = `#16181D` を作ります。
4. モード追加ボタンを押してみます。Starter で制限されることを自分の目で確認します。
5. コレクションをもうひとつ作って `Color / Dark` とし、同じ名前の変数を `#111318`、`#F2F3F5` で作ります。
6. 確認: 2つのコレクションに、同じ名前の変数が2つずつあります。

## 演習 3. 開発用プラグインで一度に作る (約20分)

1. 演習 2 で作ったファイルをそのまま使います。プラグインは同じ名前があれば新しく作らず、値だけを上書きします。
2. メニューから Plugins > Development > Import plugin from manifest を選び、`token-plugin/manifest.json` を選択します。(メニューの場所はアプリのバージョンによって、キャンバスの右クリックメニューにある場合もあります。)
3. Plugins > Development > Free Course Token Builder を実行します。
4. 確認: 画面下部に `✅ variables 18 · text styles 4 · sections 3` と表示されます。Variables に `Color / Light`、`Color / Dark`、`Spacing` があり、テキストスタイルが4つできています。
5. 応用: `code.js` の `TOKENS.colors` に `status/danger` のような色をひとつ追加して保存し、もう一度実行します。新しい変数だけが増えるか確認します。

### 困ったときは

| 症状 | 原因と解決策 |
|---|---|
| Development メニューがない | ブラウザで開いています。デスクトップアプリで開いてください。 |
| `❌ ...font...` | `TOKENS.fontFamily` のフォントがインストールされていないか、インストール後にアプリを再起動していません。 |
| 実行しても何も変わらない | 別のファイルを見ています。演習用ファイルを前面にして再実行してください。 |
