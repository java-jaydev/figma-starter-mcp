## 1. 無料プランの壁をひと目で把握 (10分)

- 進行ノート: `../../../skills/figma-build/references/limits-and-sources.md` の表を映し、「上限 - 回避策」のペアでざっと見ていきます。この講座は、実際に Starter アカウントでデザインシステムを作る中でぶつかった順番をたどる、と紹介します。
- 強調点: 数値は変わります。表に確認日と出典がある理由を伝えます。
- 想定される質問: 「普通に Professional を使えばよいのでは?」 - 個人のサイドプロジェクト、学習、小規模チームの初期段階なら無料でも十分です。制約を理解しておけば、あとで移行するときも構成がきれいに保てます。

## 2. ページの代わりに Section (20分)

- 進行ノート: Starter のデザインファイルはページが3つまでです。デザインシステムでは通常 Foundations、Components、Patterns、Playground のように多くのページを使いますが、これを1ページ内の Section で分けます。
- 画面デモ: ツールバーの Section ツール(ショートカット Shift+S)で Section を描いて名前を付けます。左のレイヤーパネルで Section がフォルダのように折りたためることを見せます。
- 残り2ページの使い方の提案: 1ページ目 = システム(Section で区分)、2ページ目 = 実験場、3ページ目 = アーカイブ。
- 演習 1 を実施 (`labs.md`)。
- 想定される質問: 「Section の中に Section は作れますか?」 - 作れます。ただし深くネストすると探しにくくなるので、2階層までをおすすめします。

## 3. モードの代わりにコレクション2つ (25分)

- 進行ノート: 変数モードにはプランごとの上限があり、Starter では実際にコレクションあたりモード1つしか作れませんでした。そこで `Color / Light`、`Color / Dark` の2つのコレクションに **同じ名前** の変数を作ります。
- コードとの対応: 開発者には、CSS の `:root` と `[data-theme="dark"]` に同じ変数名を2回定義するのと同じだと説明します。
- デメリットも正直に: モード切り替え一回で画面全体を切り替える機能は使えません。ダーク画面はダークコレクションの変数を直接バインドして別に作ります。あとで有料プランに移行したら、2つのコレクションをひとつにまとめてモード2つに変えれば済みます。
- 演習 2 を実施 (`labs.md`)。手作業で2つだけ作ってみて、「これを数十個やるとしたら?」という問いかけで次のブロックへつなげます。

## 4. 開発用プラグインで自動化 (35分)

- 進行ノート: 開発用プラグインは、デスクトップアプリで `manifest.json` を読み込んですぐ実行できます。公式ドキュメントにプランの制限や呼び出し上限の記載がないので、Starter で繰り返し作業を任せるのに向いています。
- コードを読む (10分): `code.js` を一緒に読みます。
  - `TOKENS`: データ。受講者が書き換えるのはここだけです。
  - `getCollection`、`upsertVariable`: 同じ名前があれば再利用するので、何度実行しても重複しません。
  - `buildTextStyles`: フォントは `loadFontAsync` で先に読み込まないとスタイルに指定できません。
  - `buildSections`: ブロック 2 で手作業でやったことをコードで。
  - `manifest.json` の `documentAccess: "dynamic-page"`: そのため `getLocal...Async` のような非同期 API を使います。
- 演習 3 を実施 (20分)。
- まとめ (5分): トークンを JSON に切り出して、コードリポジトリと Figma が同じ値を使うようにする方向性を紹介します。

## 5. MCP は節約して使う (10分)

- 進行ノート: Figma MCP サーバーを使うと、AI コーディングツールが Figma ファイルを読み書きできます。Starter は月間の呼び出し回数がとても少ないので、デザインシステムを MCP で作っているとすぐに上限に達します(実体験)。
- 公式ドキュメントによると、ファイルに書き込む一部のツールは上限の対象外です。上限を消費するのは主に読み取り呼び出しです。
- まとめ: 繰り返しの生成はプラグイン、MCP は「完成した画面をコードに移すとき」のような本当に必要な場面だけに。
- 想定される質問: 「上限はいつリセットされますか?」 - 月単位です。正確な基準は公式 FAQ を一緒に開いて確認します。

## 6. フォント、ライブラリ、まとめ (10分)

- フォント: 新しくインストールしたフォントは、デスクトップアプリを再起動しないと表示されません。講座前の準備物の案内に入れておきます。
- ライブラリ: Starter ではチームライブラリで共有するのが難しいです。そのため、ファイルを「トークンファイル、コンポーネントファイル」に分けず、1ファイルにまとめました。ファイル数(3つ)の上限とも合致します。
