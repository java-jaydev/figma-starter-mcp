## v0.1.1 에서 고친 것

1. **매니페스트의 IP 주소 거부.** Figma 오류 원문: `Manifest error: Invalid value for devAllowedDomains. 'ws://127.0.0.1:39917' must be a valid URL`. `devAllowedDomains` 를 `ws://localhost:39917` 하나로 줄이고 플러그인도 그 주소로 붙는다. 서버는 그대로 `127.0.0.1` 에서 받는다. Figma 는 `localhost` 를 먼저 `::1` 로 시도한 뒤 `127.0.0.1` 로 넘어가 연결했다.
2. **플러그인 UI iframe 에 `crypto.subtle` 이 없음.** 연결은 열리지만 HMAC 계산이 조용히 실패해 hello 를 보내지 못하고, 서버의 5초 제한에 끊기기를 반복했다. 화면에는 "Server not running" 이 떴다. HMAC-SHA256 을 `@noble/hashes` 로 계산하게 바꿨다. `crypto.getRandomValues` 는 있다.
3. **본체 메시지의 보낸 곳이 `parent` 가 아님.** UI 가 `e.source === parent` 인 메시지만 받게 했더니 init(저장된 비밀, 파일 이름)과 명령 결과가 모두 버려져 명령이 30초 시간 초과로 끝났다. 이 확인을 뺐다. 서버에서 오는 명령은 서명으로 검증한다.
4. **새 컴포넌트의 기본 칠은 숨김.** `bind_variable` 로 색을 연결해도 숨김 상태가 남아 안 보였다. 연결할 때 칠을 보이게 한다.
5. **`lint` 의 잘못된 지적.** 섹션의 기본 칠, 테두리, 둥글기(2)를 하드코딩 값으로 지적했다. 섹션은 이 값을 보지 않는다. 텍스트 스타일을 쓴 글자의 크기도 지적했다. 스타일이 있는 글자는 크기를 따로 보지 않는다.

플러그인 UI 와 서버 연결 기록은 Origin 헤더가 `"null"` 로 오는 것을 확인했다(R2 가정과 같음).

## 남은 일

- TEXT 컴포넌트 속성을 글자 레이어에 잇는 방법 (도구 인자 추가 또는 글자 레이어가 하나일 때 자동 연결). 그때까지 스킬에서 사용자에게 손으로 이어 달라고 안내한다.
- 연결이 열린 뒤 인증 단계에서 실패하면 UI 가 "Server not running" 만 보여 원인이 가려진다. 원인별 문구가 필요하다.
- 컴포넌트 삭제 확인창에 다른 곳에서 쓰는 인스턴스 수를 보여 주기 (`getInstancesAsync`).
- 확인창 문구 `1 nodes` 의 단수형.
- Claude Code, Gemini CLI 의 마켓플레이스/확장 설치 확인은 이번에 하지 않았다. 시험은 MCP SDK 클라이언트로 서버를 직접 띄워 했다.
